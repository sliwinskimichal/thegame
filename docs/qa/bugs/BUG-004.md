## Kroki odtworzenia
```ts
const m = new PacingModel();
m.run('complete', { ...DEFAULT_BEHAVIOUR, efficiency: NaN }).total;      // 1
m.run('complete', { ...DEFAULT_BEHAVIOUR, gameSpeed: 0 }).total;         // 2
m.run('max', { ...DEFAULT_BEHAVIOUR, gameSpeed: 0 }).total;              // 3
m.run('complete', { ...DEFAULT_BEHAVIOUR, migrantsPerHour: -10 }).tiers; // 4
percentile([], 0.5); percentile([1, 2, 3], NaN);                          // 5
```

## Oczekiwane
Parametr spoza dziedziny (NaN, ≤ 0 tam, gdzie fizycznie dodatni, ujemni migranci) → wyjątek z nazwą parametru albo wynik jawnie oznaczony (`NaN`, flaga `saturated`). `percentile` pustej próbki → wyjątek lub `NaN`.

## Faktyczne
1. `efficiency = NaN` (także `gameSpeed = NaN`): **6,93 h** zamiast ~40 h — pętla `while (done < workHours)` kończy się po pierwszym kroku, bo `NaN < x` jest fałszem. Tryb `max` daje już `NaN`. `tunnelScale = NaN` → 5,67 h.
2. `gameSpeed = 0`: każda warstwa dobija do ukrytego limitu `hours < 500` → **6305,7 h** bez sygnału (700,35 h na warstwę).
3. Tryb `max` z `gameSpeed = 0` → `Infinity` (dzielenie przez zero w części post-game), z `gameSpeed = 1e-9` → 7,4·10¹⁰ h.
4. `migrantsPerHour = -10`: populacja **-4993 … -44993**, część post-game −0,05 h; `tunnelScale = -5` skraca grę do 36,2 h.
5. `percentile([], p)`, `percentile(a, NaN)`, `percentile(a, -0.1)` → `undefined` (typ `number`); `monteCarlo(mode, 0)` + raport → `TypeError` przy `.toFixed`.

## Wpływ
Model jest jedynym dowodem 40 h / 120 h (`docs/BALANCE.md`). Raporty sterowane zmiennymi środowiskowymi (`BASES`, `GROWTHS`, `GW` → `Number('x') = NaN`) albo przyszły bot (M5) mogą podać NaN/0 i dostać liczbę, która wygląda jak wynik. Istniejący test „produces finite work” sprawdza tylko `workHours`, więc tego nie łapie.

## Weryfikacja poprawki
Cztery `it.fails('BUG-004…')` zaczynają przechodzić (zdjąć `.fails`); `tests/balance.test.ts` bez zmian (40,4 h); raport `BALANCE_REPORT=1` identyczny dla domyślnych parametrów.

## Regresja
Monte Carlo (zakresy losowania: `efficiency ≥ 0,22`, `gameSpeed 1,2–2,1` — nie mogą zacząć rzucać), turniej krzywej kosztów, `docs/design/systems/tools/economy-audit.mjs`, testy `balance-edges` „order independence” i „Monte Carlo z tego samego seeda”.
