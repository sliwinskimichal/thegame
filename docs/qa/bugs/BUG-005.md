# BUG-005 — Tekstura kafli ujawnia prawdziwy materiał nieodkrytego kafla, gdy `bg = 0` (wyciek mgły wojny)

| Pole | Wartość |
|---|---|
| Typ | błąd (utajony; kontrakt z generatorem 2.0) |
| Priorytet / waga | **P3 — średni** (spoiler/exploit: rudy widoczne przez mgłę); dziś 0 takich kafli w arenie i galerii |
| Obszar · KM | `src/render/worldTex.ts` (`sync`) vs `src/render/heightfield.ts` · M2 (generator), M1 (style czytające `uTileTex`) |
| Właściciel poprawki | engine-graphics-programmer; kontrakt `bg ≠ 0`: level-systems-designer (generator) |
| Środowisko | commit 2d29211 / 2b63f08, Node 22.23.5 |
| Częstość | 100% przy `bg = 0` |
| Test | `tests/qa/render-data.test.ts` — `it.fails('BUG-005…')` + test kontraktu „bg ≠ 0” dla areny (2 seedy) i galerii |

## Kroki odtworzenia
1. Świat 3×3 z granitu (`mat = bg = GRANITE`, odkryty); środkowy kafel: `mat = GOLD`, `bg = 0`, `flags = 0` (nieodkryty).
2. `new WorldTex(world, new LightField(3, 3))`, odczytaj `tiles.image.data[c * 4]`.
3. Porównaj z `buildHeightfield(world, 0, 0, 3, 3)` (atrybut `aMatFlags % 256`).

## Oczekiwane
Nieodkryty kafel wygląda jak skała macierzysta — ani tekstura, ani siatka nie ujawniają złota („apparent state: unknown tiles look like plain host rock”, komentarz w `worldTex.ts`).

## Faktyczne
Tekstura: **17 (GOLD)** — `bg[i] || mat[i]` spada na prawdziwy materiał. Heightfield: **4 (LIMESTONE)** — `bg[i] || M.LIMESTONE`. Dwie ścieżki tych samych danych mają różne zachowanie awaryjne.

## Wpływ
Generator, który nie ustawi `bg` dla każdego litego kafla (np. żyły wstawiane po wypełnieniu skały), pokaże shaderom (iskrzenie, kreska rud, forma minerału) rudy w nieodkrytym — gracz „widzi” złoża przez mgłę. Dotyczy wszystkich stylów czytających kanał r `uTileTex` dla nieodkrytych kafli.

## Weryfikacja poprawki
`it.fails('BUG-005…')` przechodzi; test kontraktu „arena/galeria: bg ≠ 0 dla nieodkrytych” zostaje i obejmuje generator 2.0 (dodać jego mapy, ≥ 3 seedy).

## Regresja
Mgła w arenie (`scenario=fog`), metryka `C_fog` w `metrics.py`, `tests/arena.test.ts` („hides the unexplored region”), heightfield (`FACE.UNEXPLORED`).
